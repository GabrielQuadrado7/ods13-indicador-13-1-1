**Goal:** Carregar a planilha do indicador 13.1.1 num PostgreSQL normalizado e gerar, a partir do banco, estatística descritiva, regressões linear (Y = taxa, X = ano), tabelas CSV, gráficos PNG e um resumo para o artigo.

**Architecture:** Pacote Python `ods13/` com a lógica (conexão, ETL, estatística, gráficos, relatório); dois scripts finos de linha de comando (`etl/carregar.py`, `analise/analisar.py`); SQL versionado em `sql/` (schema, seed, views). A análise lê só do banco (`ods13.vw_observacao`), nunca da planilha.

**Tech Stack:** Python 3.13, PostgreSQL 18 (local, serviço `postgresql-x64-18`), pandas, openpyxl, SQLAlchemy 2 + psycopg 3, scipy, numpy, matplotlib, python-dotenv, pytest.

**Spec:** `docs/superpowers/specs/2026-11-15-ods13-indicador-13-1-1-design.md`

## Global Constraints

- Banco: PostgreSQL 18, encoding `UTF8`, todos os objetos no schema `ods13`.
- Credenciais só em `.env` (variável `DATABASE_URL`, ex.: `postgresql+psycopg://postgres:SENHA@localhost:5432/ods13`); `.env` no `.gitignore`. Testes usam `ODS13_TEST_DATABASE_URL` (banco `ods13_teste`), nunca o banco principal.
- `...` e células vazias viram `NULL`/`NaN`, **nunca 0**. `0` da planilha é valor real.
- Nunca misturar níveis: estatística "entre UFs" usa só `nivel = 'uf'`; Brasil e regiões só aparecem como séries próprias.
- Variância e desvio padrão são **amostrais** (ddof = 1; `VAR_SAMP`/`STDDEV_SAMP`).
- CSV: separador `;`, decimal `,`, encoding `utf-8-sig` (abre direto no Excel em português).
- Gráficos: PNG, 300 dpi, títulos/eixos em português.
- Textos voltados ao usuário (mensagens, resumo, README) em português.
- Psql fica em `C:\Program Files\PostgreSQL\18\bin\psql.exe` (não está no PATH).

**Files:**
- Create: `ods13/estatistica.py`, `tests/test_estatistica.py`

**Interfaces:**
- Consumes: `ods13.vw_observacao` (Task 3).
- Produces:
  - `carregar_observacoes(engine) -> pd.DataFrame` — `SELECT * FROM ods13.vw_observacao`, `valor` como float.
  - `descritiva(valores: pd.Series) -> dict` — chaves `n, ausentes, media, mediana, variancia, desvio_padrao, minimo, maximo` (ddof=1, NaN ignorado).
  - `classe_modal(valores: pd.Series) -> tuple[float, float, int]` — `(limite_inferior, limite_superior, frequencia)`; NaN removido; k = `ceil(1 + 3.322 * log10(n))`; `numpy.histogram(valores, bins=k)`; empate → primeira classe.
  - `descritiva_por_ano(df) -> pd.DataFrame` — só `nivel == 'uf'`; índice `ano`; colunas de `descritiva` + `classe_modal_inf, classe_modal_sup, classe_modal_freq`.
  - `descritiva_por_localidade(df) -> pd.DataFrame` — uma linha por localidade (colunas `nome, nivel` + `descritiva`), ordem Brasil, regiões, UFs.
  - `@dataclass Regressao: serie: str; a: float; b: float; b_ano_2018: float; r: float; r2: float; p_valor: float; n: int` — `ŷ = a·ano + b` e `ŷ = a·(ano−2018) + b_ano_2018`.
  - `regressao(serie: str, x: pd.Series, y: pd.Series) -> Regressao` — remove pares com NaN; `scipy.stats.linregress`.
  - `regressoes(df) -> list[Regressao]` — ordem: `"Brasil"`, as 5 regiões (Norte, Nordeste, Sudeste, Sul, Centro-Oeste), `"UFs (agrupadas)"`.
